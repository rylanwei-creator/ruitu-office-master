Native MLX acceptance harness: build RitoMLXValidation, package with mlx.metallib and SwiftPM resource bundles, and specify RitoModelDirectory / RitoResultPath in its test app Info.plist. It denies network only in that test process, validates 20 generations, cancels after 3 chunks, checks recovery, and unloads. It is not included in the production application. Timing anomalies and limits are recorded in docs/Rito-AI-双模式验收.md.
