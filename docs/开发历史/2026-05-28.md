## 备注

1. **iOS 权限配置**：Info.plist 不能作为 SPM 顶级资源。以下权限需在 Xcode 项目中配置：
   - NSCameraUsageDescription（证件照拍照）
   - NSPhotoLibraryUsageDescription（证件照选图）
   - NSMicrophoneUsageDescription（语音转文字）
   - NSSpeechRecognitionUsageDescription（语音识别）
   - UIFileSharingEnabled（iTunes 文件共享）
   - LSSupportsOpeningDocumentsInPlace（原地编辑文档）

2. **iOS 构建方式**：执行 `open Package.swift` 用 Xcode 打开项目，选择 iOS Simulator 目标，Cmd+B 构建

3. **iOS 文件保存方案**：iOS 沙盒限制无法使用 NSSavePanel，当前预留 ShareLink 方案（写入 tmp 目录后通过 Share Sheet 分享）

4. **下一步**：
   - 在 Xcode 中打开 Package.swift，验证 iOS Simulator 编译通过
   - 逐个工具端到端测试（.fileImporter → 配置 → 处理 → 查看结果）
   - 适配 iOS 特有的 UI 细节（safeAreaInsets、Dynamic Island、iPad 分屏）
