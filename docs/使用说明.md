# 锐途办公大师 1.9.0 使用说明

## 工具模式
从侧栏选择文件改名、文件整理、图片处理、抠图、图片去水印、证件照、拼图、PDF、格式转换、视频压缩、音视频转换或 OCR。导入文件，核对设置与预览后执行并保存结果。

## Rito AI
点击左上角切换至 Rito AI。首次进入 AI 设置，选择本地模型或自定义云端 API。本地模型下载完成后可离线聊天；云端模式需填写自己的接口、模型 ID 和 API Key。

添加图片、PDF 或文件夹后，用自然语言说明需求。Rito 追问时可直接补充参数，无需再次添加同一附件。任务卡展示实际参数，可点击「设置参数」修改。改动后重新生成预览，确认本机执行后查看结果。结果文件支持打开、复制和在 Finder 显示。

## 拼图
普通拼图支持 1–12 张静态图片。选择布局拼图、纵向长图或横向长图；设置比例、模板、间距、背景、滤镜和文字，预览后导出 PNG/JPG。Rito 拼图任务支持 2–8 张附件。

## 目标体积压缩
轻度、均衡、强力分别以原体积减少约 30%、50%、75% 为目标。自定义可设置体积范围。必要时允许等比缩小；是否满足目标以实际输出结果为准。

## 系统与文件
支持 macOS 14 及以上、Apple Silicon。普通工具不依赖 AI 模型或云端。云端密钥保存在 macOS Keychain；模型文件单独下载。普通文件处理在本机完成；系统语音及翻译可能需要下载语言模型。

## 安装
从 GitHub 发布页下载 ZIP，解压后将应用放入「应用程序」。当前应用为 ad-hoc 签名，尚未经过 Apple 公证；请核对发布来源，不要关闭系统安全设置。
