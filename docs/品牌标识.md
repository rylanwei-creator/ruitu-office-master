# 当前品牌标识（1.1.3）

用户选定黑金 RT，并要求外部应用图标带浅灰圆角底板，软件内部只显示透明 RT。

## 软件内标识

`Sources/RuiTuOfficeMaster/macOS/Resources/Logo.png` 为透明 PNG。背景、R 的内部空洞和字母间留白采用 Alpha 透明，不添加底板。首页、各功能页和关于页面读取该文件。

## macOS 应用图标

同目录 `AppIcon.png` 为独立的圆角浅灰底板图标，底板外部透明，RT 保持较小尺寸和居中留白。
`AppIcon.icns` 由 `scripts/build-icon.sh` 与 `scripts/pack-icon.swift` 导出，包含 16、32、128、256、512 像素及各自 2x 图块；`scripts/build-app.sh` 自动执行。

设计使用内置 imagegen 编辑。最终编辑要求：黑金 RT 直接抠图，保持字形和配色，背景与空洞透明；外部图标单独采用与参考图相近的圆角浅灰底板，外围透明，字母占底板宽度约 60%。软件内未接入 AI 功能。

更新后保存当前工作、退出旧进程，再打开原文件夹的 `release/锐途办公大师.app`。系统可能暂时保留旧图标缓存。
