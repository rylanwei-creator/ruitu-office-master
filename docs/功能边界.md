# 功能边界与尚未覆盖的验证

本次修复提供可构建、可运行且通过已记录验收的版本，不等同于证明所有文件、设备和系统版本上没有问题。

- Word/PDF 转换是基础文字处理。复杂表格、图片、分页、页眉页脚、字体替换和原版式重建没有完整排版引擎支持，不能保证与 Word 的打印结果一致。
- 图片输出统一为 8-bit sRGB。PNG 编码不再做颜色量化，但 16-bit、HDR、广色域、特殊 ICC 色彩以及 EXIF/GPS 等原始元数据不保证保留。专业图像工作请核对结果并保存原始文件。多页 TIFF/动态图片不会作为普通格式转换成功处理。
- 本机未提供 WebP 编码器时不会显示 WebP 输出；HEIC、HEVC 和语音语言模型等能力依赖操作系统和设备。没有内置第三方编解码库来补齐全部格式。
- 视频以选定参数重新编码，不能保证变小，也不保证保留 HDR、所有附加音轨、字幕轨和全部元数据。常见单视频/音频轨适用；专业多轨素材应使用专用编辑工具。大视频、受保护媒体、罕见编码和跨设备性能还需专项验证。
- OCR 的识别率取决于原图、字体、语言及系统模型；复杂表格/多栏顺序和手写文字可能需要校对。不能由一张成功的测试图推断所有扫描件准确。
- 真实语音、字幕时间戳质量、全部语言离线模型和翻译语言包安装流程尚未用用户样本逐项验收。语音采用本机能力，不支持时明确报错。
- 证件照换底使用系统本机人像分割，依赖系统 Vision 能力；复杂发丝、透明眼镜、背景同色衣服或背景中其他人物可能影响遮罩。自动构图和参考线不等于证件审核规则，应核对接收方要求。工作图最长边限制 4096 像素，超过原裁切清晰度的输出会提醒。打印 PDF 的毫米尺寸已验证，尚未实测纸张/打印机的物理成品。
- 本次在 Apple Silicon 机器构建并运行。Intel 架构已编译并合并，但没有 Intel 实机运行验证；没有 macOS 14/15/后续版本的完整设备矩阵验收。
- 应用已做 ad-hoc 签名和签名一致性检查，尚无 Developer ID 签名与 Apple 公证，不能当作已经完成正式公开发行的安装包。
- 批量处理停止主要发生在文件边界，单个系统编解码步骤未必能立即中断。超大文件仍可能耗时，结果需要保存后再退出或清理缓存。

- 1.3.0 任务中心当前只管理图片处理和格式转换，不包含真正暂停、跨重启续传或自动重试。单张编码需要等系统调用结束；大量文件、网络盘、iCloud 未下载文件、外接盘拔出与磁盘耗尽仍需真实设备专项验收。
- 文件改名增加了文件身份和元数据校验，未实现持久化撤销日志及进程崩溃后的事务恢复；文件整理、重复文件清理、Excel、PDF 可视化签名和 AI 均留在后续阶段，本版不增加占位入口。
- 优化前 1.2.0 的完整备份位于原项目 backups/1.2.0；新版使用独立任务元数据，没有迁移原历史数据库模型，保留回退路径。

原始附件和旧源码保留在单独的“原项目-修复前备份.tar.gz”中。恢复时先解压到新文件夹，核对内容后再选择性取回，不要直接覆盖当前工程。

## 1.4.1 图片工具边界

抠图使用 Apple Vision 前景实例分割，依赖 macOS 14+ 本机能力与输入主体可分辨程度。自动提取全部识别前景；矩形清除是人工补充，尚未提供画笔、复杂选区和逐主体选择。

图片周边修补只做选区外边界颜色插值，适合简单背景；取样修补复制现有干净背景，没有生成式恢复能力，不承诺恢复真实遮挡细节。

图片最长边超过 4096 px 时明确提示等比缩小后的工作尺寸；输出 PNG 使用工作尺寸。尚未完成超大图片压力、Intel 实机及跨 macOS 版本验收。

视频去水印已移除；已保存的视频文件与原有视频工具保留。链接下载尚未接入。
