你可能想知道

我的照片和文件会被上传吗？＋

图片、PDF、OCR 等文件处理在本机完成。本地 AI 下载后可离线对话；自定义云端发送文字与有限上下文，不发送附件内容或文件名。网页图片小工具同样只在浏览器内处理。

为什么网页和我电脑上的版本不一样？＋

官网提供 1.9.0 正式版，适用于 macOS 14 及以上的 Apple Silicon Mac。可在软件内检查更新；下载新版本后替换旧应用。

支持 Windows 或手机吗？＋

目前桌面软件支持 macOS 14 及以上，没有 Windows、iOS 或 Android 版本。官网可在手机浏览，也可以使用网页图片小工具。

安装包经过 Apple 公证了吗？＋

当前开发构建使用 ad-hoc 签名，尚未完成 Developer ID 签名与 Apple 公证。请核对发布说明和来源。官网不会建议你关闭系统安全设置。

抠图和图片去水印能保证完美吗？＋

抠图使用系统前景分割，复杂背景、发丝和透明物体需要人工检查，目前支持框选清除残留背景。图片去水印提供周边插值及取样修补，适合简单背景，无法保证恢复被遮住的真实细节。

整理或改名之后能撤销吗？＋

改名提供撤销上次操作；文件整理在本机保存日志，可校验后尝试撤销。文件被修改、原位置被占用等情况会阻止相应撤销。复制会额外占用磁盘，移动会改变文件路径。
